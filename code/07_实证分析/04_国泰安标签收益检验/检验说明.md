# 国泰安标签收益检验

## 检验口径

本检验直接使用 CSMAR（国泰安数据库）的 DGTW（特征分组匹配方法）年度股票分配标签，按项目的日度收益重新计算组合基准和特征调整收益。历史试算采用剔除北交所的标签版本；组合形成年度按每年7月至次年6月对应。基准组合采用窗口资格池，保留符合资格的停牌及暂停上市填充日，并使用滞后3个交易日的流通市值作为权重。

这里分别保存了市值90分位提示和沪深300提示的结果。90分位指提示公司筛选口径，不是组合标签分位数。

## 图2代码

“图2_收益动态”中的两个脚本从历史聊天记录恢复：第一个保留原准备阶段，用于生成官方组合基准和目标日原始收益缓存；第二个恢复最终精确估计和绘图代码。两者仅调整了缓存及结果目录：缓存放在项目的工作目录下，重新计算的结果放在图2结果目录的“重新计算”子目录。

原图2使用的相关中间缓存此前已经清理，运行第二个脚本前需要先运行第一个。脚本仍依赖项目现有的季度面板缓存、原收益缓存、缩尾阈值及公共估计模块，并非脱离项目即可运行。日度宽面板在历史图2生成后曾更新，重新运行不保证得到完全相同的数值。本次整理没有运行这些脚本。

图2结果目录保存了两种提示口径的历史估计表、市值90分位提示图及核验文件。沪深300提示图片来自较早一次独立计算；两种提示的完整估计表来自后来的精确估计，不应把两者说成同一次输出。
