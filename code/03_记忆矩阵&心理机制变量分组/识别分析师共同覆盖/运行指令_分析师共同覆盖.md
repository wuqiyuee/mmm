## 覆盖和追加说明

同一次运行中，Full 样本会分块处理。第 1 块会新建/覆盖对应输出文件，后续第 2 块、第 3 块等会追加到同一个文件里。

如果重新运行同一个样本、窗口和 ID 口径，对应的旧 CSV 会被新的运行结果覆盖。
